# Ola City Ride Issue Analyzer — Student Package

This package contains the student-facing files for the Python Developer handover simulation.

## Files in this folder

| File | Purpose |
|---|---|
| `Ola_City_Ride_Issue_Analyzer_Student_Colab_Problem_Statement.ipynb` | Main Colab notebook to complete and submit |
| `ola_city_ride_issue_dataset.zip` | Dataset ZIP to upload into the Colab session |
| `Meeting_Transcript_Ola_City_Ride_Issue_Analyzer.docx` | Simulated workplace meeting conversation |
| `PRD_Ola_City_Ride_Issue_Analyzer.docx` | Industry-style Product Requirements Document |
| `prd_completion_checklist.csv` | Checklist for mapping completed work to PRD requirements |

## Final submission requirement

Submit only one file: the completed `.ipynb` notebook with all code, outputs, logs, report previews, AI prompt usage notes, PRD mapping, assumptions, final walkthrough, self-check, and presentation notes visible inside the notebook.

Do not submit separate output CSV files unless specifically asked by your evaluator. The notebook itself must contain visible evidence that reports were generated and previewed.

## How to use in Google Colab

1. Open `Ola_City_Ride_Issue_Analyzer_Student_Colab_Problem_Statement.ipynb` in Google Colab.
2. Upload `ola_city_ride_issue_dataset.zip` when the notebook asks for it.
3. Read the meeting transcript and PRD before solving the notebook.
4. Complete each broken/TODO section in order.
5. Fill the required notebook placeholders: Debug Fix Log, AI Prompt Usage Log, PRD Completion Mapping, Assumption Log, Report Preview Evidence, Product Walkthrough, Final Self-Check, and Presentation Notes.
6. Run the notebook from top to bottom before submission.

## Important constraints

Use Python, Pandas, and Colab-compatible widgets only. Do not use Flask, Streamlit, APIs, databases, ML models, cloud deployment, or real Ola data. All datasets are synthetic for education.
